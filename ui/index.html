配置飞书自建应用

按下面顺序做一遍即可。应用由你自己在飞书创建，本站只负责用它的 App ID / Secret 换取登录身份和发私信；Secret 相当于密码，别贴到聊天记录或仓库里。
  1. 创建应用：打开飞书开放平台 →「创建企业自建应用」，名称随意（如 AgileCampus）。
  2. 拿凭证：进入应用 →「凭证与基础信息」，复制 App ID 与 App Secret。
  3. 配回调地址：应用 →「安全设置」→「重定向 URL」，添加 http://localhost:3000/api/auth/feishu/callback。 这里必须与下一步填进 .env 的 FEISHU_REDIRECT_URI 一字不差（协议、端口、路径都要一致）； 部署在线上时换成对外域名，且飞书要求 https。
  4. 加权限与机器人：应用 →「权限管理」添加 contact:user.base:readonly（读用户基本信息，绑定用）与 im:message:send_as_bot（以应用身份发私信）； 再到「添加应用能力」里启用机器人。
  5. 发布应用：应用 →「版本管理与发布」创建版本并申请发布，由管理员审核通过。 应用没发布时，开放平台的接口会一律报无权限——这一步最容易被跳过。
  6. 填写环境变量：在本页下方「环境变量（.env）」里填 FEISHU_APP_ID、FEISHU_APP_SECRET， 并把 FEISHU_REDIRECT_URI 改成第 3 步那个地址。 FEISHU_BASE_URL 保持默认 https://open.feishu.cn 即可。
  7. 重启应用：回到「应用服务」卡片点「重启」，新配置才会被读入。
  8. 在站内绑定：打开网站 → 右上角设置 →「绑定飞书」，按提示授权； 还没登录的话，登录页也可以直接用飞书登录。
常见问题
· 回跳时报 state_error：重定向 URL 与 FEISHU_REDIRECT_URI 不一致， 或中途换了域名/浏览器，导致 state cookie 丢失。
· 提示「该飞书账号已绑定其他用户」：这个飞书账号已经绑过别的站内账号，先在原账号解绑。
· 授权页说应用不可用：应用没发布，或「可用范围」里没有你。
· 绑定成功但收不到私信：机器人能力没启用、没加 im:message:send_as_bot，或应用尚未发布。
